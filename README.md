## Portfolio website

This repository contains a responsive static portfolio built with semantic HTML, CSS, and vanilla JavaScript. It includes six project case studies, light and dark themes, mobile navigation, local project assets, a custom 404 page, and Vercel deployment configuration.

### Run locally

```bash
python -m http.server 8080
```

Open `http://localhost:8080`.

### Deploy to Vercel

The site requires no build command, dependency installation, backend, database, or environment variables. Import the repository into Vercel using the **Other** framework preset, or deploy from this directory with:

```bash
npx vercel
```

Use `npx vercel --prod` only after checking the preview deployment.
